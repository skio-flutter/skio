# uvc_camera example: USB camera viewer

Pick a UVC camera (endoscope, microscope, inspection camera or USB webcam),
grant access, and see the live preview. Change the preview size from the
menu, capture photos with the button or the camera's own hardware button, and
see them as thumbnails.

```bash
flutter run -d <android>   # Android over USB OTG
flutter run -d chrome      # Web
```
